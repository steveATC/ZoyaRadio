# Zoya Radio repository rules

- Work locally and only inside this repository.
- Preserve working features and existing user changes.
- Keep credentials and hard-coded API keys out of the project.
- Implement one milestone at a time; never silently continue to the next milestone.
- Test before declaring work ready or successful.
- Do not download large AI models or other large dependencies without explaining them and receiving approval first.
- Keep logs and instructions understandable to a non-programmer.
- Do not claim a milestone is complete until its required manual checks are complete.
