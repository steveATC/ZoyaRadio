# Research index

This index tracks external research relevant to Zoya Radio without treating it as implemented behavior or approved roadmap scope.

## Research authority rules

- **Empirical evidence** is an observation supported by the inspected source, artifact, repository, recording, or measured run.
- **Recommendation** is an interpretation or proposed application of that evidence. It remains non-binding until Steve explicitly approves it and the decision/roadmap documents are updated.
- **Brainstorming** may use research as inspiration but is not evidence, architecture, or milestone scope.
- The committed Git reports are canonical. Copies synchronized into ChatGPT Project sources are mirrors and may become stale.
- Current implementation is governed by [CURRENT_ARCHITECTURE.md](CURRENT_ARCHITECTURE.md), and approved work is governed by [ROADMAP.md](ROADMAP.md).
- Research does not change implementation, accepted decisions, Milestone 8 scope, or the roadmap automatically.

## Using and updating research

When using or updating a report:

1. Use the committed Git file as the canonical copy and record its exact provenance and inspection date inside the report.
2. Separate observed evidence from interpretation and recommendations.
3. Read the full report rather than reducing it to an unsupported one-line conclusion.
4. Note unavailable or uncertain details rather than filling gaps.
5. Update this index if the canonical path changes.
6. Update `DECISIONS.md`, `ROADMAP.md`, `PROJECT_STATE.md`, or implementation only after Steve explicitly approves a resulting change.

The local Git copy remains authoritative if an exported research snapshot, Project-source mirror, or ChatGPT discussion differs from it.
